# คู่มือการติดตั้งและใช้งาน KHALIFAH PROGRAM
## ระบบเช็คชื่อ มาเรียน ละหมาด 5 เวลา และกิจกรรม เชื่อมต่อ Google Sheets & Google Sites

## 1. วิธีเชื่อมต่อ Google Sheets (ฐานข้อมูลฟรี 100%)

ระบบนี้ได้รับการออกแบบให้ใช้ **Google Sheets** เป็นฐานข้อมูลหลักผ่าน **Google Apps Script (GAS)** โดยทำตามขั้นตอนง่ายๆ ดังนี้:

### ขั้นตอนที่ 1: สร้าง Google Sheet ใหม่
1. ไปที่ [Google Sheets](https://sheets.google.com) แล้วสร้างสเปรดชีตว่างใหม่ 1 ไฟล์ (เช่น ตั้งชื่อว่า `KHALIFAH_DATABASE`)
2. ที่เมนูด้านบน คลิกที่ **ส่วนขยาย (Extensions)** ➔ **Apps Script**

### ขั้นตอนที่ 2: วางโค้ด `Code.gs`
1. ลบโค้ดเริ่มต้นในหน้าต่าง Apps Script ออกทั้งหมด
2. เปิดไฟล์ [Code.gs](file:///f:/AI%20สร้างระบบเช็คมาเรียน%20มาละหมาด%20มาเข้ากิจกรรม/Code.gs) ในโฟลเดอร์นี้ คัดลอกโค้ดทั้งหมดไปวางลงในโปรเจกต์ Apps Script
3. กดปุ่ม **บันทึก (รูปแผ่นดิสก์)** 

### ขั้นตอนที่ 3: เผยแพร่เป็นเว็บแอป (Deploy as Web App)
1. คลิกที่ปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน ➔ เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกรูปฟันเฟือง ⚙️ ด้านซ้าย ➔ เลือกประเภทเป็น **เว็บแอป (Web app)**
3. กรอกรายละเอียด:
   - **คำอธิบาย (Description):** `Khalifah Program API v1`
   - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (Me - บัญชีอีเมลของท่าน)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก: ต้องเลือก Anyone เพื่อให้ระบบรับ-ส่งข้อมูลได้)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. กดยอมรับสิทธิ์การเข้าถึง (Authorize access) ของ Google ➔ เลือกบัญชีของคุณ ➔ คลิก Advanced ➔ คลิก Go to ... (unsafe) ➔ Allow
6. ท่านจะได้รับ **URL ของเว็บแอป (Web App URL)** เช่น:
   ```
   https://script.google.com/macros/s/AKfycbx.../exec
   ```
7. คัดลอก URL นี้ไว้

### ขั้นตอนที่ 4: เชื่อมต่อในแอป
- เปิดหน้าเว็บ Khalifah Program คลิกที่ปุ่ม **ฟันเฟือง ⚙️ (ตั้งค่า)** ที่มุมขวาบน
- นำ URL ที่คัดลอกมาวางในช่อง **Google Apps Script Web App URL** แล้วกด **บันทึกการตั้งค่า**
- ระบบจะสร้างตาราง `Students`, `PrayerLogs`, `AttendanceLogs`, `Activities`, `Admins`, `Settings` ลงใน Google Sheet ให้อัตโนมัติทันที!

## 2. วิธีนำขึ้น Google Sites (ฝังระบบลงใน Google Sites)

ท่านสามารถนำเว็บแอปนี้ไปฝังใน **Google Sites** เพื่อให้นักเรียนและผู้ปกครองใช้งานได้สะดวกผ่านทุกอุปกรณ์:

### วิธีที่ 1: ฝังโดยใช้ Web App URL (ง่ายที่สุด)
1. เปิดหน้าแก้ไขเว็บไซต์ใน [Google Sites](https://sites.google.com)
2. เมนูขวามือ เลือกแถบ **แทรก (Insert)** ➔ คลิก **ฝัง (Embed)**
3. เลือกแถบ **ตาม URL (By URL)** ➔ วาง URL ของ Google Apps Script ที่ Deploy แล้ว
4. กด **แทรก (Insert)** แล้วขยายขนาดกล่องให้เต็มหน้าจอตามต้องการ

### วิธีที่ 2: ฝังด้วยโค้ด HTML iframe
ในกรณีที่นำไฟล์เว็บไปโฮสต์ไว้บน Cloud / GitHub Pages / Firebase หรือต้องการควบคุม iframe:
```html
<iframe 
  src="URL_เว็บแอปของท่าน" 
  style="width: 100%; height: 95vh; border: none; border-radius: 16px;" 
  allow="geolocation; camera; microphone"
  allowfullscreen>
</iframe>
```
*(หมายเหตุ: ต้องอนุญาต `geolocation; camera` เพื่อให้ฟังก์ชันเช็คพิกัดและกล้องสดทำงานได้อย่างสมบูรณ์)*

## 3. สรุปฟังก์ชันการทำงานหลักของระบบ

### 3.1 การสมัครและเข้าสู่ระบบ
- **การสมัครใหม่**: กรอกชื่อ-สกุล, โรงเรียน, เบอร์โทรผู้ปกครอง, วันเดือนปีเกิด (ใช้เป็นรหัสผ่าน), รหัสนักเรียน (สมัครได้คนละ 1 ครั้ง ป้องกันการซ้ำ) และระดับชั้น (ม.1 - ม.6)
- **การเข้าสู่ระบบ**: ระบุรหัสนักเรียน และวันเดือนปีเกิด

### 3.2 การแก้ไขปัญหาเมื่อเลื่อนชั้นปีใหม่ (ม.5 ➔ ม.6)
1. **ทางที่ 1 (นักเรียนอัปเดตเอง)**: 
   - นักเรียนไปที่เมนู **"โปรไฟล์ / เลื่อนชั้น"** 
   - จะมีกล่อง **"อัปเดตข้อมูล / เลื่อนชั้นปีการศึกษา"** ให้นักเรียนเลือกชั้นใหม่ (เช่น ม.6) แล้วกดบันทึกได้ทันที
2. **ทางที่ 2 (แอดมินเลื่อนชั้นยกห้อง)**:
   - แอดมินเข้าหน้า **ผู้ดูแลระบบ** ➔ แถบ **"เลื่อนชั้นปีอัตโนมัติยกห้อง"**
   - เลือกชั้นเดิม (เช่น ม.5) และชั้นใหม่ (เช่น ม.6) แล้วกด **"ยืนยันเลื่อนชั้นปีนักเรียนทั้งหมด"** ระบบจะปรับระดับชั้นให้นักเรียนทั้งห้องในคลิกเดียว
